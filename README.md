# MuscleLog PWA

Персональный фитнес-дневник: тренировки, питание, калории и БЖУ.

## Установка на iPhone
1. Откройте сайт через Safari.
2. Нажмите «Поделиться» → «На экран Домой» → «Добавить».

## Возможности
- Цели: 2950 ккал, Б 140 г, Ж 75 г, У 429 г.
- Пример программы на 4 дня.
- Журнал упражнений, подходов, повторений, веса и RPE.
- Дневник питания с граммовками и БЖУ.
- История веса.
- Экспорт и импорт резервной копии JSON.

Данные хранятся локально в браузере. Синхронизации между устройствами пока нет.
