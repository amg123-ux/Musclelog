# MuscleLog PWA

Персональный фитнес-дневник: тренировки, питание, калории и БЖУ.

## Возможности

- Индивидуальные параметры профиля: возраст, рост, вес и пол.
- Личные дневные цели: калории, белки, жиры и углеводы.
- Персональный четырёхдневный план: переименование дней, добавление, изменение, удаление и перемещение упражнений.
- Журнал тренировок и питания, история веса.
- Экспорт и импорт резервной копии JSON.
- Синхронизация настроек и записей через Supabase для каждого аккаунта.

## Установка на iPhone

1. Откройте сайт через Safari.
2. Нажмите «Поделиться» → «На экран Домой» → «Добавить».

## Supabase setup

1. Выполните `supabase/schema.sql` в SQL Editor вашего Supabase проекта. Это создаёт профили, `user_data`, триггер новых аккаунтов и политики RLS: пользователи читают и изменяют только собственную запись `user_data`; управление аккаунтами остаётся в защищённой Edge Function.
2. Создайте первый аккаунт, затем назначьте его администратором в SQL Editor: `update public.profiles set role = 'admin' where email = 'your@email';`.
3. Разверните административную функцию: `supabase functions deploy admin-users`. Она использует `SUPABASE_URL` и `SUPABASE_SERVICE_ROLE_KEY` в окружении Supabase Edge Functions. Храните service-role key только как серверный секрет Supabase; не добавляйте его в сайт, GitHub Pages или репозиторий.
4. В Supabase Auth добавьте адрес опубликованного GitHub Pages сайта в Site URL и Redirect URLs, чтобы ссылки приглашений возвращали в приложение.

Клиент использует только публичный publishable key. Профиль, цели, программа и журнал каждого пользователя сохраняются в его JSON-поле `public.user_data.data`.
